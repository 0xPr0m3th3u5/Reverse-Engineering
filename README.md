# Reverse-Engineering

A hands-on repository documenting my journey into reverse engineering,
binary analysis, debugging and vulnerability research.

The repository contains notes, experiments, tooling, challenges solutions,
CTF write-ups and research projects.

## Focus Areas

- x86-64 Assembly
- C and low-level programming
- Linux ELF binaries
- Static analysis
- Dynamic analysis
- GDB
- Ghidra
- IDA Pro
- Binary exploitation
- Malware analysis
- Vulnerability research

## Repository Structure

| Directory | Description |
|-----------|-------------|
| `00-foundations` | Computer architecture and low-level concepts |
| `01-assembly` | x86-64 assembly notes and exercises |
| `02-tools` | Reverse-engineering tools and workflows |
| `03-binary-formats` | ELF, PE and other executable formats |
| `04-static-analysis` | Static binary analysis |
| `05-dynamic-analysis` | Debugging and runtime analysis |
| `06-crackmes` | Crackme solutions and analysis |
| `07-ctf-writeups` | CTF reverse-engineering write-ups |
| `08-malware-analysis` | Malware analysis research |
| `09-vulnerability-research` | Binary vulnerabilities and research |
| `10-projects` | Personal reverse-engineering projects |
| `scripts` | Automation and analysis tooling |
